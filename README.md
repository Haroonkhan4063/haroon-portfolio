# Muhammad Haroon Khan | Developer Portfolio

A dark, neon-themed personal portfolio showcasing my full-stack and data analytics work, with case studies, tech stacks, live demos and a downloadable resume.

**Live site:** https://YOUR-PORTFOLIO-URL.vercel.app

## Features

- Fully responsive layout for mobile, tablet and desktop
- Animated hero with a rotating neon ring around the profile photo
- Skills section with glowing animated progress bars
- Project cards with descriptions, tech-stack pills, GitHub and live demo links
- Experience and certifications timeline
- In-page resume viewer with a PDF download button
- Contact form that opens the visitor's email client

## Tech Stack

React 18, Vite, Tailwind CSS, Framer Motion. Deployed on Vercel.

## Getting Started

```bash
git clone https://github.com/Haroonkhan4063/YOUR-REPO-NAME.git
cd YOUR-REPO-NAME
npm install
npm run dev
```

Build for production with `npm run build` and preview it with `npm run preview`.

## Project Structure

```
public/
  haroon.jpg            Profile photo
  resume.pdf            Downloadable resume
  resume-preview.png    Image shown in the resume viewer
src/
  App.jsx               All page sections and components
  data.js               Projects, skills, experience and links
  index.css             Tailwind layers and custom styles
```

To update content, edit `src/data.js`. If you change the resume, replace both `resume.pdf` and `resume-preview.png`.

## Deployment

1. Push this repository to GitHub.
2. Import it on [Vercel](https://vercel.com). The Vite preset is detected automatically.
3. Click Deploy.
